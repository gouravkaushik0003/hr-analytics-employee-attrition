# 📊 HR Analytics & Employee Attrition Analysis

## 📌 Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on employee attrition data using **MySQL** for data querying and **Python (VS Code)** for data visualization. The primary goal is to uncover key factors driving workforce turnover and provide data-driven insights to improve employee retention.

---

## 🛠️ Tech Stack & Tools
- **Database Management:** MySQL Workbench
- **Programming Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **IDE:** Visual Studio Code (Jupyter Extension)
- **Version Control:** Git & GitHub

---

## 📈 Key Findings & Insights
- **Baseline Attrition Rate:** The dataset reflects an overall employee attrition rate of **16.12%** (237 out of 1,470 total employees).
- **Impact of OverTime:** Employees working **OverTime** showed a significantly higher attrition rate compared to those with no overtime.
- **Job Satisfaction Link:** Low Job Satisfaction (Level 1) directly correlates with high attrition (~22.8%), whereas satisfied employees (Level 4) showed half the attrition rate (~11.3%).
- **Key Correlated Features:** Strong positive correlation observed between `JobLevel` & `MonthlyIncome`, as well as `Age` & `TotalWorkingYears`.
